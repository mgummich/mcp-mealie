# Security Policy

## Supported Versions

Only the latest release is supported with security updates. Releases are
listed in [CHANGELOG.md](CHANGELOG.md).

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3   | :x:                |

## Reporting a Vulnerability

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/mgummich/mcp-mealie/security/advisories/new).
Please do not open a public issue for a vulnerability.

Expect an acknowledgement within a week. If the report is accepted, a fix
ships in the next release and the advisory credits you unless you ask
otherwise; if it is declined, you get the reasoning.
